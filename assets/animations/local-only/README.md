# Personal-only animation experiments

Put locally accessible personal-use clips, rigs or test models in this folder when their access or
redistribution terms do not allow them in the public repository. Git ignores every file here except
this guide, and the production `build:anim` pipeline does not read this directory. This keeps local
experiments free to explore while protecting the existing public build.

Keep a brief source note for each asset you try:

| Asset | Source URL or project | Local use | Important restriction | Status |
|---|---|---|---|---|
| Example |  |  |  | not downloaded |

Do not bypass payment or access controls. Ask before buying anything or starting a subscription.
