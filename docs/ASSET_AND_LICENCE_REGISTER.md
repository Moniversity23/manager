| Item | Why not |

| **SoccerDribble: all code** | No licence from its author. The README identifies it as a Sapienza University "Interactive Graphics" final project by its student author. The MIT text in the README sits inside a code block with a placeholder copyright ("my soccer game"), and the lab's docs carry similar texts ("socccer dribble", "my soccer asset 3d model"). These were added by someone other than the author and do not grant rights. Studied only; behaviours were reimplemented independently |
| SoccerDribble `public/models/player.glb` (55 MB, Mixamo rig) | Unknown origin, no licence; far too heavy for 22 players |

## Rules applied

* Only licences that allow commercial use without payment are accepted; a licence that cannot be
  verified means the asset is not shipped.
* A row goes into the register before an asset is used; the MIT notice travels with any MIT material.
* No real clubs' crests, kits or players; no paid or non-commercial assets.
